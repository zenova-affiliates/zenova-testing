Third-party infrastructure costs—such as your custom domain name (e.g., via Namecheap), web hosting/cloud deployment (e.g., GitHub Pages, Cloudflare, Vercel, AWS), or paid third-party API keys (e.g., OpenAI, Stripe, Calendly)—are owned directly by you and billed separately.
